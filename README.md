# Iskino Village

**Опубликованный сайт:** https://savokingi.github.io/iskino-village/

Одностраничный адаптивный сайт на HTML, CSS и JavaScript. В проекте использованы фотографии из [публичного канала Iskino Village](https://t.me/iskino_village). Шрифты и изображения хранятся локально; для просмотра не нужны сборщик и внешние зависимости. Сетка и адаптивность находятся в `styles.css`, фирменная арт-дирекция по мотивам опубликованных карточек — в `art-direction.css`.

Шрифты Manrope и Prata распространяются по лицензии SIL Open Font License; тексты лицензий находятся рядом с файлами шрифтов в `assets/fonts`.

## Открыть локально

Откройте `index.html` в браузере. Для проверки через локальный сервер можно выполнить:

```powershell
node scripts/serve.cjs
```

Затем откройте `http://127.0.0.1:4173`.

## Бронирование

Форма составляет сообщение с датами, числом гостей и интересом к бане и открывает WhatsApp владельцев. Она не показывает занятость, не рассчитывает цену и не подтверждает бронирование. Актуальные стоимость и условия подтверждаются в переписке.

Перед публикацией стоит проверить контактный номер, ссылку на точку в 2ГИС и формулировки о доме, а также заменить фотографии более качественными оригиналами, если они доступны.
